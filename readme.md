# gADB

Графическая оболочка которая помогает просматривать логи с андроид устройств

Для работы требуется python 3.10 или новее

## Запуск с помощью кода 

```
    git clone repo url
    poetry install
    poetry run gadb
```




## Установка в систему
Для установки в систему требуется наличия pythin 3.10 и выше, pip 

Пакеты whl и tar.gz можно скачать в разделе Releases

```
    pip3 install path to whl/tar.gz
```
